# BookTrack
BookTrack è una piattaforma dove gli utenti possono: ● Registrarsi e autenticarsi tramite Bearer Token (JWT). ● Cercare e salvare libri utilizzando l'API di Open Library. ● Creare scaffali personali di libri da leggere. ● Segnare i libri come "da leggere", "in lettura" o "letti". ● Aggiornare il proprio avanzamento di lettura
